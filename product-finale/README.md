## 安装 · Install

1. 把 ZIP 存到 MatePad Edge 上。<br>Copy the ZIP to the MatePad Edge.
2. 在 Aira 中打开「自定义主页」，选择这个 ZIP。<br>In Aira, open 自定义主页 and choose the ZIP.
3. 导入之后，灵感台就是 Aira 的起始页。<br>From then on, Lucent is Aira's start page.

八个版本的包 `id` 相同：导入 6.0.4 会在原处更新已安装的 6.0.3、6.0.2、6.0.1、5.9.7、5.9.4、5.1.3 或 5.0，本机的设置、日志与场志全部保留。仓库根目录是网页版（`src/`），请导入这里的 ZIP。

All eight packages share one `id`, so importing 6.0.4 updates 6.0.3, 6.0.2, 6.0.1, 5.9.7, 5.9.4, 5.1.3 or 5.0 in place and keeps its settings, notes and chronicle. The repository itself is the web edition (`src/`); import a ZIP from here.

## 按交付原样保存 · Kept as shipped

八个 ZIP 都按交付时的字节原样保存，文件名也是验收时的原名：前面括号里是交付日期，后面是那一版的名字。包内的清单保留当时的写法：5.0 的内部名称是「名片 · Profile Card」，那是灵感台最初的名字；5.1.3、5.9.4、5.9.7、6.0.1、6.0.2、6.0.3 与 6.0.4 名为 Lucent Next。`npm run check` 会重新计算并核对下面八个摘要。

All eight ZIPs are kept byte for byte as shipped, under the names they were signed off with: the date of delivery in brackets, then that build's name. The manifests inside keep the words of their day: 5.0 calls itself 名片 · Profile Card, Lucent's first name, and 5.1.3, 5.9.4, 5.9.7, 6.0.1, 6.0.2, 6.0.3 and 6.0.4 are Lucent Next. `npm run check` recomputes and verifies all eight digests below.
